# 30-day plan: qualified founder conversations

Aim: a steady stream of real conversations with early-stage founders. No promise of traffic, interviews or offers. Each action can be done without changing the site design.

## Week 1: groundwork
- Merge the site update. Check the live page, the share preview (paste the URL into the LinkedIn Post Inspector and an X draft), and every link.
- Send the résumé PDF so it can be added as public/resume.pdf (the site has no résumé link yet).
- Enable Vercel Web Analytics. Optionally set up OpenPanel using docs/ANALYTICS.md.
- Pick the one project you want to lead with (CipherBill or HealthyChef). Write a short, true summary of what you built and how you tested it.
- Make a list of 20 early-stage startups whose product you can speak about specifically.

## Week 2: start outreach
- Send 5 to 8 personalized messages from docs/OUTREACH-TEMPLATES.md, one at a time. Use the campaign links so you can see what works.
- Write one technical post from real work, for example a lesson from a merged PR or from CipherBill. Post on LinkedIn and X.

## Week 3: show real work
- Share one demo video (CipherBill or HealthyChef walkthrough) on X and LinkedIn with a plain description.
- Take part in one or two relevant developer communities by helping or commenting. No promotion posts. If you share a project on Hacker News or similar, follow their rules and do it once.
- Send another 5 to 8 personalized messages.

## Week 4: follow up and review
- Send one follow-up to each person who did not reply, once.
- Look at analytics: which source brought visits, which links got clicks. Only trust it if there are enough visits to mean something.
- Note which messages got replies and rewrite the weakest template.
- Pick the next 20 companies.

## Rules
- Every claim in a message must be one you can show a link for.
- No bulk or copy-paste sends.
